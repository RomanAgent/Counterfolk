# Counterfolk 实施方案

Counterfolk 把产品上市前的关键问题变成可复现实验。团队可以比较两个方案，查看各市场的模拟漏斗，决定哪些假设值得进入真人试点，再把汇总结果用于校准下一轮实验。

## 第一阶段 · 可运行的实验台

| 模块 | 交付 |
| --- | --- |
| 世界与居民 | 在浏览器 Worker 中按随机种子生成最多 100,000 个独立合成个体。支持多国家、语言、文化偏好和买家分群。可在地图上选择市场，并查看样本个体的模拟行为。 |
| 模拟渠道 | 电商和实体店采用各自的模拟曝光和购买路径。实体店以渠道行为模型表达。 |
| 实验 | 配置硬件或 App、A/B 价格、产品吸引力、本地化程度、渠道、周期和目标。App 单独测安装、激活或付费。 |
| 检视 | 显示分地区、人群和渠道的分母、转化漏斗、按首次曝光日归属的趋势、A/B 差异和退出原因。结果可导出，最近记录存储在当前浏览器。 |
| 校准 | 导入按实验汇总的 CSV，检验指标、窗口、渠道和分组口径。训练集估计分组偏差，独立留出集报告校准前后的绝对误差。 |

默认场景是随身空气监测器，A/B 比较采用同一批合成买家和同一随机种子。默认市场、阈值与人群只是演示先验。转化率使用已曝光人数作分母。目标线用于初筛，达到目标的方案进入真人试点。

## 第二阶段 · 建立现实验证基线

1. 选择一个实际产品、市场和渠道，收集来自真实小流量试点的曝光及转化计数。为实验预先声明事件、分母、窗口和主指标。
2. 保存每次模拟的引擎版本、种子、参数和聚合结果。按独立实验划分训练、留出结果，比较校准前后的绝对误差和 A/B 排序。
3. 比较不同市场、渠道和指标的表现。每新增一个市场，先验证当前行为参数能否解释当地试点，再扩展覆盖。

## 第三阶段 · 持续演化的世界

- 将短期模拟扩展为持续的离散事件世界，记录家庭预算、长期偏好、库存、城市活动、社会关系和跨渠道行为。将结果按事件日志、版本和快照存入数据库，支持重放和并行实验。
- 以定时队列驱动常规行为，将商品理解、访谈和解释交给少量经过抽样的 LLM Agent。记录调用成本、模型版本和行为偏差，并与规则基线比较。
- 开放世界场景和人群配置格式，增加社会关系、竞争商品、地理门店、广告触点与实验 API。按同一事件口径接入实际业务数据。

当前 MVP 的十万规模指独立规则 Agent 的单次实验运行。持久生活世界、可导航的实体门店与全量 LLM 决策属于后续阶段。
